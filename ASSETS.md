# Reused user assets

- `assets/stabi.webp`: unchanged copy of `assets/stabi-front-fixed.webp` from the user's repository, https://github.com/Youngliee/Stabi-survive/blob/main/assets/stabi-front-fixed.webp.
- `assets/block-stabi.png`, `block-mev.png`, and `block-slippage.png`: unchanged user uploads `1000347245.png`, `1000347384.png`, and `1000347385.png`, respectively. The game displays these through cropped SVG viewports, clips the exterior matte on the two obstacle images, and rotates the MEV display for vertical pieces. Labels and artwork are supplied pixels, not recreated text or illustrations. The full PNG files are preserved.
- The landing page reuses these three PNGs for the hero portrait and block guide. Its visual shell is adapted from the user-owned `Youngliee/Stabi-survive/index.html`, source blob `cc02383a735dc84c9c7896bcbca8451b4ed8a4d4`. The hero uses the same original-image portrait crop as the victory screen. No additional illustration was generated.
- `assets/stabilizer-logo.webp`: unchanged copy of the user-owned repository asset `Youngliee/Stabi-survive/assets/stabi-s-logo-cropped.webp`, source blob `2f758727457e9f91b43efb9002631eb902c813d8`.
- Puzzle layouts are original generated configurations, verified for legal solutions. The interface uses functional board geometry and inline control icons; no external fonts or third-party scripts are needed.
- Sliding sounds and the victory chime are original procedural effects in `sound.js`; no music recording or external audio asset is used. The victory scene now displays the supplied running Stabi from `block-stabi.png` in a small portrait frame, using the source region x=208, y=110, width=535, height=620. The full original PNG remains unchanged.
- Downloadable scorecards use that same portrait crop with exact score data, rating markers, and typography in `results.js`. No new illustration is used. A generated extraction candidate was rejected because its checkerboard background was opaque; it is not included in this Site.
