# Stabi Escape

Community-made, unofficial puzzle game inspired by Stabilizer.

## Gameplay

- 15 sliding-block puzzle levels
- Guide the STABI block to the exit on the right
- Horizontal blocks represent **Slippage**
- Vertical blocks represent **MEV**
- Move targets award up to 3 stars per level
- Indonesian gameplay UI with undo, restart, and level select
- Up to 3 one-move hints per level
- Progress and best moves are saved locally in the browser

## Run locally

Open `index.html` in a browser, or deploy the repository as a static site on Vercel / GitHub Pages.

No wallet required. No player name required.
